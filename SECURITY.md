# Política de seguridad

## Reportar una vulnerabilidad

**No abras un issue público.** Usa **Security → Report a vulnerability** en este repositorio (reporte privado). Respondemos en un máximo de 5 días hábiles.

## Versiones soportadas

Solo la última versión publicada en [Releases](../../releases) recibe correcciones de seguridad.

## Cómo protegemos el código

Consulta [docs/seguridad.md](docs/seguridad.md): gestión de secretos con Vault (OIDC), firma y procedencia de artefactos, y escaneos automáticos en DEV (Semgrep, Trivy, Gitleaks, SonarQube, Dependency-Track).
